CORE LOGIC VERIFICATION:
─────────────────────────────────────────────────────────────────────────────

Decision Path (useCoastalReadingGated):
  1. If premium tier → allow (no blocking)
  2. If spotLat/Lon null → allow (no data to gate)
  3. If isCurrentGeolocation === true → allow (live GPS)
  4. If home spot (≤2km) → allow (home unlimited)
  5. If 7-day quota expired → allow (new quota window)
  6. If within same quota spot (≤2km) → allow (no re-charge)
  7. Else → BLOCK (reading=null, isBlocked=true, no PMTiles fetch)

Persistence Pattern:
  - Read: useMemo (pure, idempotent)
  - Write: useEffect (side-effect only, safe for React 18+)
  - Storage key: seayou_free_coastal_probe_v1
  - Format: JSON { lat, lon, ts }
  - Soft enforcement: clearable, incognito-bypassable (upsell friction)

Network Prevention:
  - When blocked: pass null coords to useCoastalReading()
  - Result: NO PMTiles fetch initiated, no API call made
  - Map layer stays invisible (no heatmap rendering)
  - Verified by Dashboard destructuring: reading=null when blocked
