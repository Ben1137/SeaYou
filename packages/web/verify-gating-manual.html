🧪 E4 Verification: Coastal Dynamics Free-Tier Gating

PREREQUISITE Make sure the SeaYou app is open in another tab at http://localhost:5173

Test 1: Set Free Tier & Monitor .pmtiles

This will:

  1. Set subscriptionTier = 'free' in localStorage
  2. Set up .pmtiles request interception
  3. Reload the app

Test 2: Verify UI & Gating

Once free tier is set:

  1. Look for the Breaking Waves toggle with a 🔒 lock icon
  2. Click the Breaking Waves button
  3. Verify a paywall appears and the layer stays off
  4. Check DevTools Network tab for .pmtiles requests (should be ZERO)

Test 3: Switch to Premium & Compare

This will:

  1. Switch to subscriptionTier = 'premium'
  2. Reload the app
  3. You should see NO lock icon and layer renders on click
  4. .pmtiles requests should NOW fire

Instructions for Manual Verification

Free Tier (after Step 1):

  1. UI Check: Look for Breaking Waves toggle in the left panel under "Coastal Dynamics"
  2. Lock Icon: Should show a 🔒 icon next to the button
  3. Click Test: Click "Breaking Waves" → should show "Premium Feature" paywall
  4. Network Check:
    • Open DevTools (F12)
    • Go to Network tab
    • Filter by "pmtiles"
    • Click Breaking Waves again
    • Should see ZERO requests (0 pmtiles downloaded)
  5. Screenshot: Take a screenshot of:
    • The Breaking Waves button with lock icon
    • The Network panel showing zero .pmtiles requests

Premium Tier (after Step 3):

  1. Lock Icon Gone: The 🔒 should disappear
  2. Click Test: Click "Breaking Waves" → layer renders, no paywall
  3. Network Check:
    • Open DevTools Network tab
    • Filter by "pmtiles"
    • Click Breaking Waves
    • Should see multiple .pmtiles requests firing
  4. Screenshot: Take a screenshot of:
    • The Breaking Waves button WITHOUT lock icon
    • The rendered breaking wave heatmap on the map
    • The Network panel showing .pmtiles requests
